# Plateside, the link

Plateside takes the guesswork out of what to cook, what to buy and when, sized to your weight goal and shaped by your blood work. The static app, built from the private repository by `labtrack web build` and published by `tools/publish.py`. Code only: nothing anyone types into the app ever reaches this repository or the host that serves it. Open https://justintroy-stack.github.io/plate-app/ in Safari and add it to the home screen.
